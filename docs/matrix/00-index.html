The Genesis Elimination Matrix — Master Index

A set of interlocking documents that partition every possible theory of what exists, where it came from, what we are, what we can know, and what we ought to do. The set is built so that any named theory, religion, or intuition has exactly one home cell, and so that eliminating cells is logically valid.

This replaces the informal four-pillar list from the Gemini conversation (see ../notes/genesis-elimination-matrix.md) with a partition built from exhaustive splits. The four pillars survive as named regions of the new map; see 02-genesis.md §6.

Cell address notation

A theory's address is a string of axis values, for example:

A1 B1 C2 D2b | M2c N1 | F1

read as: terminal necessary ground (A1), graspable in principle (B1), matter-like substrate (C2), unauthored and brute (D2b); constructivist meta-ethics (M2c) with consequentialist norms (N1); knowable in principle with a foreseeable test (F1).

Axis values are defined in the document that owns the axis. A theory that is silent on an axis gets ? for that slot. A theory that spans several values gets them in braces, C{1,2}.

Reading order

  1. 01-axioms.md for the rules.
  2. 02-genesis.md for the main map.
  3. 07-fog-front.md and 08-to-nyn.md for what "knowable" means and where we are.
  4. 06-morality.md for how each origin cell constrains ethics.
  5. 10-elimination-rules.md before trying to cross anything off.
  6. 12-named-theories-index.md to find any specific theory.
